# docs/

| File / folder | What it is |
|---|---|
| `DESIGN_DOC.md` | Canonical design: pillars, locked decisions, architecture, roadmap. Wins over any brief. |
| `CODE_GUIDE.md` | How the code is laid out and the rules every change follows. |
| `ARCH_PLAN.md` | Horde / performance architecture plan. |
| `MODEL_BUDGET.md`, `PROFILING_PLAYBOOK.md` | Enemy rig budgets and the profiling procedure. |
| `CHANGELOG.md` | Per-version ledger of what shipped. |
| `git-workflow.md` | Branch, commit and PR rules (summary lives in `CLAUDE.md`). |
| `briefs/` | Milestone and per-version briefs, named by version (e.g. `v0.9.0-brief.md`). |
| `prompts/` | Build prompts for the next batch. Finished ones move to `prompts/done/`. |
| `lab-reports/` | One report per batch: what changed, test counts, what was checked in-engine. |

Asset credits are in `CREDITS.md` at the repo root.
